# AI prompt - start of a session

Back to [[START HERE]]

Paste this at the start of every chat with your AI (change the folder name).

```
Before we work, read my game vault in the folder "My Game":
1. How you think  (how I decide; follow it)
2. Working rules  (rules that always apply)
3. Game overview  (every system and where its scripts are)
4. Open questions (decisions waiting for me)
5. The last few entries in Timeline

Then tell me in 3-5 lines what you understood and what's open.

While we work:
- Explain the cause / plan in plain words before changing anything.
- Ask me before anything with Robux, players' money, saved data or deleting my work.
- When you finish a task: report "cause -> fix -> how you tested",
  then update the vault: a Timeline entry, the feature page,
  Open questions, and How you think if I decided or corrected something.
```

## Shorter version (for small jobs)
```
Read "My Game/How you think" and "My Game/Working rules" first, then: <your task>.
Log it in the vault when you're done.
```
