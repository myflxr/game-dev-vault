# AI prompt - write a spec

Back to [[START HERE]]

Not sure how to describe a feature? Let the AI interview you, then write the spec.

```
I want to add a feature to my game: <one sentence, e.g. "a pet that follows you">.

Read "My Game/How you think" and "My Game/Game overview" first.
Then ask me up to 8 short questions (with a suggested answer for each)
about anything that's unclear: how it looks, phones, saving, Robux,
what must NOT change.

After I answer, write the spec using "My Game/Specs/_Spec template"
and save it as "My Game/Specs/Spec - <name>.md". Don't build anything yet.
```

## Tip
Answer with **"ai"** or **"you decide"** for anything you don't care about. The AI then picks, says what it picked, and keeps it easy to change.
