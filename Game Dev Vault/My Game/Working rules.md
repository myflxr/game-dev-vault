# Working rules

Back to [[My Game]] · Why: [[How you think]]

Rules the AI follows on every task. Short and strict. Change them whenever you like.

- **Read the vault first:** [[How you think]], this page, [[Game overview]] and the spec.
- **Log everything here:** every task gets a [[Timeline]] entry, the feature page is updated, [[Open questions]] stays current, and [[How you think]] grows when you decide something.
- **Find the cause first**, say it in plain words, then fix it at the source (no quick hacks).
- **Back up before big changes:** copy scripts into `ServerStorage/_Backup_<name>` and list them in [[Backups and tools]]. Delete backups only when I say so.
- **Never break** saving, purchases or the main game loop. Old saved data must still load.
- **Test in Play** (and on phone size) before saying it's done. Report: *cause → fix → how it was tested*.
- **Ask before:** anything touching Robux / players' money, wiping or changing saved data, deleting my work.
- **Big multi-step jobs:** do all the steps, then one report at the end.
- **Save the place** (Ctrl+S) after each round of changes.
