**Game Dev Vault 1.0**: a free Obsidian template that gives your AI a memory while you build a game.

## What's inside
- **START HERE**: the 5-minute setup and the build loop
- **How you think / Working rules**: your taste and rules, read by the AI before it works
- **Game overview, Timeline, Open questions, Backups and tools**: what exists, what was done, what's waiting for you
- **Specs / Features**: one page per feature request and per finished system
- **AI prompts**: start-of-session prompt, "interview me and write the spec" prompt, ready `CLAUDE.md` for Claude Code
- **Templates**: spec, feature page, timeline entry, bug report

Everything is filled in for an example Roblox game (**Pizza Rush**) so you can see what good notes look like.

## Use it
1. Download **`Game-Dev-Vault-v1.0.zip`** below and unzip it.
2. Install [Obsidian](https://obsidian.md) (free) → **Open folder as vault** → pick `Game Dev Vault`.
3. Open **START HERE**.
